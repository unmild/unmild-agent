Each turn runs on a background thread. The model is called via ureq (blocking HTTP, rustls). Tool calls come back as JSON; the agent executes list_dir/read_file/write_file/etc. inside the sandbox, posts permission requests via Approver channels if needed, and loops until the model stops calling tools. AppState::tick drains progress, permission and reply channels once per frame.

Compared to cloud coding agents, Unmild Agent runs locally, natively, with real OS integration. No browser IDE, no Electron. You keep data in your folder; the only network calls are to your configured API base URL. Trade-off: Windows only, and you supply the model (no hosted intelligence).

Seconds for small edits, minutes for multi-file refactors. Effort level bounds the reply budget: Low is fastest/cheapest, Max allows deep multi-step loops. You can Stop any turn and the thread bails at the next boundary.
